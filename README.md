# java-news2-learning-project
A beginner Java project exploring simplified NEWS2 scoring logic using fictional observations.

Java NEWS2 Scoring Learning Project

## About

This is a beginner Java project inspired by NEWS2 scoring. It uses fictional observations to practise assigning scores based on predefined ranges.

## What I Practised

* Java classes and objects
* Constructors and methods
* One-dimensional and two-dimensional arrays
* For loops and conditional statements
* Calculating a total score

## Example

The program takes fictional observation values, calculates individual scores, and adds them to produce a total.

## What I Learned

This project helped me practise breaking a problem into smaller methods, using arrays to store ranges and scores, and testing different inputs.

## Disclaimer

This is an educational programming exercise, not a clinically validated NEWS2 calculator. It must not be used for patient assessment or clinical decision-making.
